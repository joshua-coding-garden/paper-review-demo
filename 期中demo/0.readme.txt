投稿審查系統（期中 demo）

1. 建資料表
   用 Adminer（或 psql）連到 mydb，執行 papers.sql
   連線設定在 db.py：postgresql://postgres:12345@localhost:5432/mydb

2. 安裝套件（裝過就跳過）
   pip install "fastapi[standard]" "psycopg[binary,pool]" itsdangerous

3. 啟動（在這個資料夾裡）
   fastapi dev main.py
   瀏覽器開 http://127.0.0.1:8000

測試帳號（密碼都是 1234）
   author1、author2：作者
   editor1：編輯

檔案說明
   main.py           登入/登出、掛上作者與編輯的 router
   auth.py           chkLogin(角色)：沒登入轉登入頁、角色不對回 403
   db.py             資料庫連線池（老師的範例）
   routes/author.py  作者：清單、新增、編輯、刪除、送出
   routes/editor.py  編輯：待審清單、看內容、通過、退回
   templates/        5 個頁面 + base.html 共用外框

狀態流程
   編輯中 --(作者送出)--> 審查中 --(編輯通過)--> 已通過
                          審查中 --(編輯退回)--> 編輯中
